Full backend for an ecommerce. The system has user JWT-based authentication with cookies, CSRF token protection, and stripe payment implementation. The project is not completed and the system has several errors. The code is messy, it doesn't follow a layered architecture where routes, business logic, and database operations are separated. Also, it doesn't have documentation nor deep error handling. Also, it lacks atomicity, transactions and the isolation levels and consistency were not considered when making this project because I did not know about them. However, even though it needs refactoring due to the previously mentioned issues, the project allowed me to learn about backend and about implementing a full system.
